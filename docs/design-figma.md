# GachaSLop — дизайн

[Макет в Figma](https://www.figma.com/design/dtWrXSmACPSKAkQF1X6Ww7?node-id=2-2)

Состав: desktop 1440 px, mobile 390 px, форма импорта, состояния загрузки и истёкшей ссылки, компоненты и палитра.

Шрифт: Golos Text. Тема: графитовая, мятный акцент. Цвета редкости: 3★ — голубой, 4★ — лиловый, 5★ — золотой.

Данные в Figma демонстрационные. В `web/` реализован адаптивный React-интерфейс
на основе desktop и import design context: палитра, Golos Text, карточки,
навигация и диалог. Статистика берётся из API, неизвестный гарант и неполная
история имеют явные подписи. Фиктивные прогресс-бары до гаранта не перенесены:
бэкенд пока не даёт проверенный порог для каждой pity-группы.

Мобильный design context был недоступен из-за лимита Figma MCP: responsive
верстка адаптирует полученные desktop-компоненты, без обещания pixel-perfect
соответствия отдельному мобильному фрейму.

Баннеры перенесены из последнего согласованного локального HTML-макета.
Период расположен над названием, таймер — между фразой персонажа и элементом/
оружием. Теперь состав, сроки, таймер и календарь подключены к Go API для
всех четырёх игр. Демонстрационные баннеры удалены из фронтенда. Изображения
HoYoverse/Kuro соответствуют текущему составу: полноразмерные арты HoYo
подбираются по ID через Enka, у WuWa пока используются обложки объявлений.
Объединённая фаза персонажей ZZZ отображается отдельными карточками S-ранговых
персонажей, каждая со своим артом, названием и строкой в календаре. Период и
семейство pity сохраняются из источника. Общий список A-ранга отмечен как данные
фазы, поскольку API не разделяет его по персонажам. Оружейный баннер не меняется.
Прозрачные арты увеличены до композиции на всю высоту карточки. Обложки WuWa
заполняют весь фон через `object-fit: cover`; тёмный градиент обеспечивает
контраст текста. На телефонной ширине используется вертикальный градиент и
отдельное кадрирование. Период остаётся над названием, таймер — под описанием.
